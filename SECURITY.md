# Security and privacy

Token Trace is designed to run locally. It reads local Codex rollout logs only
to produce aggregate Token statistics. It does not require an API key and does
not upload session logs to a Token Trace server.

The one-command installer downloads source from this GitHub repository and,
when required, the official Node.js distribution from `nodejs.org`.

To report a security issue privately, contact the repository maintainer rather
than posting session data or secrets in a public issue.
