# Third-party notices

## Node.js runtime

The one-command installer may download the official Node.js Windows x64 runtime
from `nodejs.org` only when Node.js 22 or newer is not already available.
Node.js is distributed under the MIT License. See the Node.js distribution for
its complete license and third-party notices.

Token Trace does not bundle or transmit Codex session logs. The runtime is used
only to run the local Token Trace server on the user's own computer.
